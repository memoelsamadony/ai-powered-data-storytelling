# Country maps for the dataset pages — design

Date: 2026-08-11
Branch: `feat/frontend-viz-phase-1`

## The problem

Both datasets are `country × year` tables, but the interface only ever shows the
world aggregate: a year series in `StoryChart` and four hand-picked preview rows.
The geographic dimension — the fact that measles cases and vaccine coverage are
wildly uneven between countries, and that the "progress" story hides a widening
gap — is invisible. A reader cannot see where the story is happening.

## What we are building

A generic country choropleth component, rendered on the datasets page and in the
generate studio's comparison step. It is driven entirely by data the dataset
declares: it renders whatever metrics it is given, and if a dataset carries no
country data it does not render at all.

Scope is the front-end only. Country figures are illustrative mock data, like
every other number in this app.

## Non-goals

- No zoom, pan, or projection switching.
- No country drill-down page.
- No runtime map library, and no runtime geo fetch.
- No change to `StoryChart`, `DatasetChart`, or the tone/metric charts.

## Architecture

Four units, each independently understandable.

### 1. `scripts/build-world-map.mjs` — build-time, run by hand

Reads Natural Earth 110m country polygons (`world-atlas`, public domain),
projects them once with `d3-geo`'s **Equal Earth** projection, simplifies and
rounds the coordinates, and writes `lib/data/world-geo.ts`.

Equal Earth is an equal-area projection. Mercator inflates high-latitude
countries by 3–14×, which on a choropleth misstates the very quantity the colour
is encoding — the same class of defect as the dual-axis chart this repo keeps as
a cautionary exhibit in `components/charts/dataset-chart.tsx`.

`world-atlas`, `topojson-client`, and `d3-geo` are **devDependencies**. They are
never imported by application code and never reach the browser.

**Contract:** run `node scripts/build-world-map.mjs`; it rewrites
`lib/data/world-geo.ts` and prints the resulting byte size. Deterministic — the
same input always produces the same file, so the output is committed and CI
never needs to run it.

### 2. `lib/data/world-geo.ts` — generated, committed

```ts
/** GENERATED by scripts/build-world-map.mjs — do not edit by hand. */
/** Emitted from the projected bounds, not hand-written. */
export const WORLD_VIEWBOX: string;
export interface WorldShape { id: string; name: string; d: string }
export const worldShapes: WorldShape[];
```

The script fits the projection to a 1000-unit width and derives the height from
Equal Earth's own bounds, so the aspect ratio is whatever the projection gives
rather than a number we assert here.

`id` is ISO 3166-1 alpha-3, the join key to the dataset. `d` is a projected SVG
path in viewBox coordinates. Coordinates are rounded to one decimal place.

**Budget: the file must not exceed 120 KB.** If simplification cannot hit that,
the task stops and we reconsider rather than shipping a heavy bundle quietly.

### 3. Data contract — added to `lib/data/datasets.ts`

All fields optional, so a dataset without country data is valid and simply gets
no map.

```ts
export interface CountryMetric {
  /** Stable key, used to look values up in CountryStat.series. */
  key: string;
  label: string;
  unit: string;
  /** Picks the colour ramp: alarm-ward or calm-ward. */
  polarity: "higher-is-worse" | "higher-is-better";
  /**
   * Four ascending class breaks → five bins. Declared, never computed from the
   * visible year: with a year scrubber, recomputed bins would make a country
   * change colour because the scale moved rather than because its value did.
   */
  breaks: [number, number, number, number];
  /** Decimal places for display. Default 0. */
  decimals?: number;
  /** false = shown in tooltip and table, never mapped. Default true. */
  mappable?: boolean;
}

export interface CountryStat {
  /** ISO 3166-1 alpha-3 — joins to WorldShape.id. */
  iso3: string;
  name: string;
  /** metric key → one value per index of `countryYears`. null = no data. */
  series: Record<string, (number | null)[]>;
}

// Added to the Dataset interface:
  /** The map's own timeline. Deliberately coarser than `series`. */
  countryYears?: number[];
  countryMetrics?: CountryMetric[];
  countryStats?: CountryStat[];
  /** Shown under the map, e.g. "WHO / WUENIC · illustrative sample". */
  countrySourceNote?: string;
```

A columnar shape (metric → array parallel to `countryYears`) rather than a row
per country-year: roughly a third the bytes, and it makes "this country has no
figure for this year" a plain `null` rather than a missing row to search for.

### 4. `components/charts/country-map.tsx` — the component

```tsx
"use client";
export function CountryMap(props: {
  years: number[];
  metrics: CountryMetric[];
  stats: CountryStat[];
  sourceNote?: string;
  height?: number;
  /** Drop the heading where the surrounding card already names the data. */
  compact?: boolean;
  showTable?: boolean;
}): JSX.Element | null;
```

Returns `null` when `stats` is empty or no metric is mappable — the "if there
are no countries in the data, don't display the map" rule lives in one place, so
neither call site has to guard.

Nothing about measles or child mortality appears in this file. It renders the
metrics it is handed.

**Behaviour**

- **Metric toggle** — a segmented control built from
  `metrics.filter(m => m.mappable !== false)`. Hidden when only one qualifies.
- **Year scrubber** — a range input over `years`, with a play/pause button that
  advances roughly one year per 900 ms and loops. Autoplay never starts on its
  own. Under `prefers-reduced-motion: reduce` the play button is not rendered
  and the slider still works.
- **Colour** — five sequential bins from the tokens in `lib/charts/tokens.ts`.
  `higher-is-worse` ramps toward `alarm`; `higher-is-better` ramps toward
  `calm`. Ramp steps are added to `tokens.ts` as named exports, not inlined, and
  are validated with the dataviz palette validator before being committed.
- **No data** — a grey diagonal-hatch `<pattern>`, never the palest bin. A
  country with no figure must not read as a country with a low figure. The
  legend carries an explicit "no data" swatch.
- **Interaction** — each country is focusable (`tabIndex=0`) and responds to
  hover and keyboard focus with a tooltip listing every metric for that country
  and year, including the non-mappable raw counts. `aria-label` on each path
  states country, metric, value, year.
- **Table twin** — a `Show as table` disclosure matching `SeriesTable` in
  `components/charts/story-chart.tsx`: one row per country for the visible year,
  every metric as a column, sorted by the active metric.
- **Legend** — bin edges printed as numbers with the unit, plus the no-data
  swatch.

## Data flow

```
scripts/build-world-map.mjs  ──(run by hand, once)──▶  lib/data/world-geo.ts
                                                              │
lib/data/datasets.ts ──countryYears/Metrics/Stats──▶ CountryMap ──joins on iso3
                                                              │
                        app/datasets/page.tsx  ────────────────┤
                        components/generate/comparison.tsx ────┘
```

The component joins `worldShapes` (all ~180 countries) against `stats` by
`iso3`. Every shape renders; only matched ones get a bin colour.

## The country data

Around 45 countries per dataset, spread across every inhabited continent so the
map reads as a map, at five anchor years each.

**Measles × MCV1** — years `[1990, 2000, 2010, 2019, 2023]`

| key | label | unit | polarity | mappable |
| --- | --- | --- | --- | --- |
| `cases_per_million` | Measles cases per million | per million | higher-is-worse | yes |
| `mcv1_coverage` | MCV1 coverage | % | higher-is-better | yes |
| `cases` | Reported cases | cases | — | no |
| `population` | Population | millions | — | no |

Raw case counts are deliberately not mappable. A choropleth of case counts is a
population map — India and Nigeria are darkest in every year regardless of what
happened — so the rate is mapped and the count is disclosed in the tooltip and
table.

**WHO child mortality** — years `[1990, 2000, 2010, 2019, 2022]`

| key | label | unit | polarity | mappable |
| --- | --- | --- | --- | --- |
| `under5_mortality` | Under-5 mortality | per 1,000 live births | higher-is-worse | yes |
| `life_expectancy` | Life expectancy | years | higher-is-better | yes |

Both are already rates, so both are mappable.

Figures are drawn from published WHO/OWID/UN IGME values where known and
plausibly interpolated where not, consistent with how `series` and `previewRows`
already work. `countrySourceNote` states this on the page, and the file header
comment states it in the source.

## Integration

**`app/datasets/page.tsx`** — inside `DatasetBlock`, in the existing chart card
below `StoryChart`, separated by the standard hairline rule. The dataset column
is `lg:grid-cols-2`, so the map is narrow; it keeps its aspect ratio and the
scrubber wraps under the metric toggle at that width.

**`components/generate/comparison.tsx`** — inside the existing *"The data all
three stories describe"* card at line 134, below `StoryChart`, `compact`.

Both call sites render `<CountryMap …/>` unconditionally and rely on the
component's own `null` return, rather than each duplicating a
`countryStats?.length` check.

## Error handling and edge cases

| Case | Behaviour |
| --- | --- |
| Dataset has no `countryStats` | Component returns `null`. Nothing renders, no empty card. |
| A metric is missing for one year | `null` in the array → that country hatches as no-data for that year only. |
| `iso3` matches no shape | Ignored for drawing; still listed in the table so the mismatch is visible rather than silent. |
| Value above the top break | Clamped into the top bin. The legend's top label reads `500+`. |
| All values for a metric are null in the visible year | Map is fully hatched; a line under the legend says no data for that year. |
| JS disabled / pre-hydration | The SVG is server-rendered at the first year with the first metric; only the toggle, scrubber, and tooltip need JS. |

## Testing

The repo has no test runner and adding one is out of scope. Verification is by
running the app and checking, on both pages and both datasets:

1. `npm run build` and `npx tsc --noEmit` pass, `npm run lint` clean.
2. `lib/data/world-geo.ts` is under 120 KB.
3. Both maps render; countries with data are coloured and the rest are hatched.
4. The metric toggle switches ramp and legend; the ramp direction matches
   polarity (high coverage reads calm, high case rate reads alarm).
5. Scrubbing changes colours; a country whose value is unchanged between two
   years keeps its exact colour — proving breaks are fixed.
6. Hover and keyboard focus both produce the tooltip; every metric is listed.
7. The table twin opens and matches the visible year.
8. No hex literal appears in `country-map.tsx`.
9. The page does not scroll horizontally at 360 px wide.

## Risks

- **Bundle size.** The geometry is static path data in a client component. The
  120 KB cap is a hard gate, not a guideline.
- **Fabricated country figures.** ~45 countries × 5 years × 2–4 metrics is a
  meaningful volume of illustrative data. It is labelled as illustrative in the
  UI and in the source, exactly as `series` and `previewRows` already are.
- **`world-atlas` install.** Requires network at build-authoring time. Once
  `world-geo.ts` is committed, no one else ever needs those packages.
